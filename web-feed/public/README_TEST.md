# Chamber Protocol (回音室協定) - 測試人員指南

歡迎參與 **Chamber Protocol（去中心化社交迴響室）** 的內部測試！
本外掛能幫助您將 Facebook 貼文加密/明文備份至 Arweave 去中心化區塊鏈上，並生成您專屬的「轉世時光軸」，保障您的數位資產自主權。

---

## 📥 步驟 1: 下載並安裝瀏覽器外掛

1.  **下載外掛壓縮檔**：
    點擊下載並解壓縮外掛檔案：[chamber-extension.zip (14KB)](https://studio.milkcat.org/echo/chamber-extension.zip)
2.  **開啟 Chrome 擴充功能頁面**：
    在 Google Chrome 瀏覽器網址列輸入 `chrome://extensions/` 並斷行。
3.  **啟用開發人員模式**：
    開啟頁面右上角的**「開發人員模式」**（Developer mode）開關。
4.  **載入外掛**：
    點選左上角的**「載入未封裝項目」**（Load unpacked）按鈕，選擇剛才解壓縮出來的 `extension` 資料夾。
5.  **完成安裝**：
    安裝成功後，您會在 Chrome 工具列看見一個名為 **Chamber Protocol** 的外掛圖示（拼圖展開選單內）。

---

## 🔐 步驟 2: 設定您的轉世 ID（可選）

1.  點擊工具列的 **Chamber Protocol** 外掛圖示。
2.  面板中會自動為您生成一個隨機安全錢包。
3.  如果您想自訂接收貼文的錢包地址，可以點選**「連結錢包」**來綁定您的 MetaMask 地址。若不綁定，外掛預設會使用安全託管模式替您自動備份。

---

## 👥 步驟 3: 開始備份 Facebook 貼文

1.  開啟您的 [Facebook 網頁](https://www.facebook.com)。
2.  在動態牆或您的個人主頁中，瀏覽任何貼文，您會發現貼文帳號名稱下方多出了一個靛藍色的 **`[🔒 備份至 Web3]`** 按鈕。
3.  點擊該按鈕：
    *   按鈕會顯示 `⏳ 備份中...`，此時外掛會自動抓取文字、原文連結與圖片。
    *   備份完成後（約 5~7 秒），按鈕會顯示為綠色的 **`✅ 已備份至 Arweave`**。

---

## 時光軸 步驟 4: 檢視您的「重生時光軸」

1.  開啟您的擴充功能面板，點擊 **「進入我的時光軸」** 連結。
2.  或是直接在瀏覽器輸入以下網址（將括號替換為您的**臉書 User ID 雜湊值**，可在外掛面板上複製）：
    `https://studio.milkcat.org/echo/[您的 FB-User-Hash]/all`
3.  您將看見您剛才備份下來、附帶原文連結、且圖片永不破圖的 Web3 重生時光軸！

### 💡 開發偵錯小技巧
*   **偵錯模式**：若在外掛備份時勾選「偵錯模式」，貼文將預設被隱藏。只有在網址後方加上 `?debug=true` 時才會顯示，並會帶有紅色的 `DEBUG` 標籤，非常適合測試時使用。
